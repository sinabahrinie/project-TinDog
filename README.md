# TinDog 🐶

TinDog is a responsive dog dating website inspired by popular dating applications. It allows dogs to discover and connect with other dogs nearby through a simple and attractive user interface.

## 🌟 Features

- **Hero Section:** A welcoming introduction with app download buttons.
- **Features Section:** Highlights the main benefits of the application.
- **Testimonials:** Displays customer feedback.
- **Press Section:** Showcases featured media brands.
- **Pricing Plans:** Three subscription plans for different needs.
- **Footer:** Includes navigation links and copyright information.
- **Responsive Design:** Adapts to different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.8
- SVG Icons
